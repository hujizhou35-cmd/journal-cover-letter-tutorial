# Human-authored benchmark protocol

A previous or expert-authored cover letter can be analyzed only with explicit permission. It is a benchmark for editorial choices, not a gold standard and not a factual source for the current submission.

Analyze separately:

- what problem the human chose to foreground;
- how methods were converted into design advantages;
- which results were selected or omitted;
- how novelty and reader value were framed;
- where promotional language was used;
- where claims may exceed manuscript evidence;
- paragraph order, rhythm, tone, and document layout.

Transfer the reasoning pattern only when it fits the current manuscript and journal. Never carry over names, titles, journal details, submission branch, identifiers, declarations, hidden metadata, or unsupported claims.

Permission boundaries:

- `FORMAT_ONLY`: layout properties only;
- `FORMAT_AND_TONE`: layout plus general voice, not distinctive wording;
- `MAXIMUM_SUITABLE_WORDING`: reuse only wording that remains factually and contextually correct;
- `FACT_CHECK_ONLY`: no stylistic or wording transfer;
- `ANONYMOUS_EXPERT_BENCHMARK`: analyze decisions and tradeoffs, then write independently;
- `NONE`: do not use the file.
