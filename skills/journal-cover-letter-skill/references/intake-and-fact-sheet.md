# Intake and fact sheet

Build a traceable fact sheet before writing. Prefer the signed or submission-ready title page for author details, the latest main manuscript for study content, and explicit submission-system instructions for declarations.

## Required fields

- manuscript title and short title;
- article type and submission branch;
- target journal, if known;
- study question and design;
- population, setting, data source, sample size, or included-study count;
- primary methods and analytical framework;
- central findings with exact direction and magnitude when important;
- novelty candidates: new finding, taxonomy, concept, framework, dataset use, or practice implication;
- evidence boundaries and known limitations relevant to claims;
- corresponding-author block;
- originality, exclusive submission, ethics, consent, conflicts, funding, data/code, preprint, and AI-use statements as applicable.

## Status rules

Give each field one status:

- `verified`: supported by a named file and location;
- `conflict`: two credible sources disagree;
- `missing`: required but not supplied;
- `not_applicable`: clearly unnecessary for this branch.

Never resolve a conflict by silently choosing the most convenient value. Present a compact table with source notes and ask the user to resolve hard conflicts.

## Candidate contribution scoring

Score candidates for novelty, evidential support, decision relevance, journal-reader relevance, and distinctiveness. Use the score to support judgment, not replace it. Routine search dates, database counts, table construction, or formatting choices are credibility details rather than headline contributions unless the manuscript makes them substantively novel.
