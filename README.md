# Journal Cover Letter Skill v1.0

[简体中文](README.zh-CN.md)

The first open-source release of a Skill and Codex Plugin for writing academic journal cover letters from manuscript files.

Version 1.0 focuses on reliability. It checks manuscript facts, asks how an older cover letter may be used, researches the target journal's current official guidance, and reviews the finished draft before delivery.

> **Status:** Legacy. New users should normally choose v2.1.

## What it does

1. Reads the manuscript, title page, supplements, and any previous cover letter.
2. Shows the author the facts and main contributions it found.
3. Waits for the author to resolve missing or conflicting information.
4. Checks current official information from the target journal.
5. Drafts the letter and checks facts, claims, declarations, and placeholders.
6. Returns the text, optional DOCX, and anything the author still needs to confirm.

Version 1.0 uses one general writing approach for all article types. Later versions separate Original Research and Reviews because they need different ways of presenting value to an editor.

## Quick start

Attach your files and ask:

> Read these manuscript files and help me write a cover letter for [Journal]. Show me the facts and main contributions first, and wait for my confirmation before drafting the final letter.

## Install

Download the v1.0 standalone Skill package or Plugin package from the matching GitHub Release. Do not mix it with files from another version.

## Privacy and limits

The examples are fictional. Do not commit confidential manuscripts, private submission messages, personal information, or documents with hidden metadata.

The Skill cannot guarantee acceptance. Authors remain responsible for the facts, declarations, ethics, conflicts of interest, journal policy, and final submission.
