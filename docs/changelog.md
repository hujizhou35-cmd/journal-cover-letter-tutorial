# Changelog

Public tags use `v1.0` through `v3.2`. Package manifests use strict semantic versions.

## 3.2.0 — 2026-08-06

- Kept manuscript facts authoritative when an expert benchmark contains stale or conflicting details.
- Required both a performance-analysis signal and a science-mapping signal when Bibliometrics mode is `BOTH`.
- Added a direct bridge from verified journal scope or reader need to a specific mapped contribution.
- Removed submission-system-only choices from cover-letter prose unless explicitly required.

## 3.1.0 — 2026-08-06

- Required a manuscript-specific bibliometric signature and specificity floor.
- Preserved central three-to-six-domain taxonomies when they carry the paper's identity.
- Added blind baseline and semantic benchmark-convergence rules.

## 3.0.0 — 2026-08-06

- Added Bibliometrics as a third writing route.
- Separated the journal's official article label from the Skill's reasoning route.
- Added performance-analysis, science-mapping, field-map, and metric-boundary logic.

## 2.3.0 — 2026-08-06
