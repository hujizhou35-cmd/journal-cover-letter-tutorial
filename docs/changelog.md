# Changelog

Git tags use v1.0, v2.0, v2.1, and v2.2. Package manifests use 1.0.0, 2.0.0, 2.1.0, and 2.2.0.

## 2.2.0 — 2026-08-05

- Reworked Research letters around one editor-facing decision spine.
- Put the scientific phenomenon and finding ahead of method complexity.
- Translated methods into capabilities and results into one conclusion-level cluster.
- Added omission discipline and benchmark-convergence checks.
- Kept the v2.1 Review route and evidence boundaries unchanged.

## 2.1.0 — 2026-08-03

- Improved Review cover letters so they explain what the synthesis changes in the field's understanding.
- Added measured promotion while keeping facts and scientific claims traceable.
- Replaced generic journal praise with a specific explanation of reader relevance.
- Made length flexible unless the journal or user sets a limit.
- Treated expert-authored letters as comparison material, not standard answers.

## 2.0.0 — 2026-08-03

- Added different writing logic for Original Research and Reviews.
- Made Research letters tell one clear scientific story, while Reviews explain what changes after the evidence is synthesized.
- Increased persuasive force without weakening evidence limits.
- Added limited revision rounds so the process stops clearly instead of rewriting forever.

## 1.0.0 — 2026-08-03

- Added manuscript fact checking and author confirmation.
- Added current official journal research.
- Added permission choices for using an older cover letter.
- Added final checks for missing information, risky wording, and DOCX output.
