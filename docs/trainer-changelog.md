# Skill Trainer changes

## v0.2.0 — 2026-08-06

- Distinguishes a clean first baseline from a genuinely blind full iteration loop.
- Requires a fresh, expert-free generation context for every candidate round.
- Records context boundaries, packet hashes, output hashes, and reveal timing.
- Checks shared projects, cross-chat memory, custom instructions, and inherited history before making a blind-test claim.

## v0.1.0 — 2026-08-05

- Introduced blind baseline generation, expert comparison, transferable rule extraction, candidate versioning, holdout checks, protected-route regression tests, and human approval.
