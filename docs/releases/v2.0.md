# Journal Cover Letter Skill v2.0 (Legacy)

Version 2.0 separates Original Research and Review/Synthesis routes, adds scientific story selection, calibrates persuasion without weakening evidence boundaries, and uses bounded state loops with explicit stop reasons.

v2.0 将 Original Research 与 Review/Synthesis 分流，加入科学故事选择，在不削弱证据边界的前提下提高说服力，并使用带明确停止原因的有界状态循环。

This release is retained for reproducibility. New users should normally choose v2.1.

本版本用于复现与比较；新用户通常应选择 v2.1。
