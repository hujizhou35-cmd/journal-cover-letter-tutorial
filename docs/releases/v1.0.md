# Journal Cover Letter Skill v1.0 (Legacy)

The first reliable version. It checks manuscript facts, researches current journal guidance, asks permission before using an older cover letter, and checks the finished draft for missing or risky content.

首个注重可靠性的版本。它会核对手稿事实、查询期刊当前要求、在使用旧版 Cover Letter 前询问权限，并检查最终草稿中的遗漏和高风险表述。

Kept for comparison. New users should normally choose v2.1.

本版本用于比较；新用户通常应选择 v2.1。
