# Journal Cover Letter Skill v1.0 (Legacy)

The first fact-grounded release. It adds a status-aware Fact Sheet, current official journal research, explicit permissions for previous cover letters, unified `1-5-1-1` editorial iteration, deterministic DOCX utilities, and readiness gates.

首个以事实为基础的版本：加入状态化 Fact Sheet、目标期刊最新官方信息检索、既往 Cover Letter 使用权限、统一 `1-5-1-1` 编辑迭代、DOCX 工具及就绪门槛。

This release is retained for reproducibility. New users should normally choose v2.1.

本版本用于复现与比较；新用户通常应选择 v2.1。
