# Changelog

All notable changes are documented here. Plugin manifests use semantic versions; Git tags use the public release labels.

## [2.1.0] - 2026-08-03

### Added

- Review field diagnosis, synthesis intervention, and editorial-thesis selection.
- Controlled editorial uplift with fact, interpretation, and significance zones.
- Journal-conversation fit instead of generic aims-and-scope praise.
- Adaptive length governed by editorial function rather than a universal word count.
- Human-authored benchmark protocol: benchmark, not gold standard.

### Changed

- Review/Synthesis is now thesis-driven while the v2.0 Research route remains intact.

## [2.0.0] - 2026-08-03

### Added

- Separate Original Research and Review/Synthesis narratives.
- Scientific story selection for original research.
- Persuasion-preservation and claim-strength calibration.
- Bounded intake, story, draft-audit, and compression loops with explicit stop reasons.

## [1.0.0] - 2026-08-03

### Added

- Manuscript fact sheet with verified, conflict, and missing states.
- Permission-aware use of previous cover letters.
- Current official journal-research protocol.
- Unified `1-5-1-1` editorial iteration and bounded audits.
- Deterministic payload, DOCX, placeholder, and risk-language utilities.
